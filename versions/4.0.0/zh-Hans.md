# Phrabbit 用户指南

Phrabbit 是一款用于外语听力练习的 A/B 区间循环应用。你可以把音频文件、视频文件、音乐库曲目、播客和 YouTube 链接作为学习材料添加进来，然后反复听指定片段、跟读并录下自己的声音，或通过听写写下所听内容。应用还支持语音转文字字幕、单词本、已保存的跟读录音与听写记录，以及学习记录。

> 注：本指南中的按钮名称以应用里的英文 UI 为准。根据设备语言设置，部分文字可能会显示为本地化语言。

本指南适用于 **Phrabbit 4.0.0**。播放器布局会适应 iPhone 或 iPad 的可用窗口宽度。

## 1. 开始使用

### 1-1. 首次启动 - 引导页
首次打开应用时，会看到介绍 Phrabbit 基本流程的引导画面。

1. **波形与 A/B 区间循环** - 一边看见声音的形状，一边设置起点 A 和终点 B，只重复那一段。
2. **字幕、单词本和复习流程** - 看字幕、保存不熟悉的单词，并积累学习记录。

最后一页可以选择以下两种操作之一。

| 按钮 | 说明 |
|---|---|
| **Try with a sample** | 打开示例音频，跟着播放器教程试用 |
| **Skip** | 直接进入主屏幕 |

### 1-2. 免费试用
完成引导后会开始 **3 天免费试用**。试用期间可以自由体验高级版功能。试用中，播放器上方会显示 **Trial** 横幅，点按横幅即可打开高级版购买页面。


## 2. 主屏幕与资料库

主屏幕是所有学习材料汇集的地方。本地音频、视频文件、音乐库曲目、播客单集和 YouTube 链接会一起显示在同一个资料库列表中。

![主屏幕](images/iphone/05-home.png)
*▲ 同时显示文件、播客和 YouTube 项目的主屏幕*

### 2-1. 界面布局

| 位置 | 元素 | 说明 |
|---|---|---|
| 顶部 | Phrabbit 标志 | 向下滚动列表时缩为简洁标题 |
| 右上 | 加号按钮 | 打开添加菜单 |
| 右上 | 搜索按钮 | 打开资料库搜索 |
| 右上 | 更多按钮 | 打开设置和资料库整理命令 |
| 标志下方 | All / Favorites | 至少标记一个收藏项目后显示的筛选器 |
| 中上 | Recent | 最近练习过的项目达到 2 个以上时显示 |
| 中部 | Library | 显示所有学习材料 |
| 底部 | Home / Wordbook / Progress | 切换主屏幕、单词本和学习记录 |

首次使用或资料库为空时，可以用中间的 **Add** 按钮直接添加材料。添加至少一个项目后，应用可能会显示一次小提示，告诉你加号按钮的位置。设置现在位于**更多**按钮中，不再是单独的齿轮按钮。

### 2-2. 收藏与文件夹
点按资料库行末尾的 **⋯**，或长按该行，可打开同一个管理菜单。选择 **Add to Favorites** 可将项目加入收藏，选择 **Move to Folder…** 可整理项目。对普通资料库项目选择 **Info**，可以查看完整标题、类型、时长、播放位置、添加日期或区间数、文件夹位置等无法全部显示在行内的信息。文件夹菜单包含 **Rename**、**Move to Folder…** 和 **Delete**。

![行管理菜单](images/iphone/22-row-actions.png)
*▲ 可见的 ⋯ 与长按会打开同一菜单*

![行信息面板](images/iphone/27-row-info.png)
*▲ Info 显示行内放不下的信息*

至少有一个收藏项目后，标志下方会出现 **All / Favorites** 筛选标签；选择 **Favorites** 会显示整个资料库中的收藏项目，不受文件夹位置影响。

使用 **更多 > New Folder** 创建文件夹。已有文件夹时，**更多 > Select** 可以选择多个项目并一起移动。选择时，点按左上角的 **Select All** 可选中当前列表中的全部文件和文件夹，再点按一次（**Deselect All**）即可全部取消。移动文件夹时，其中的内容也会一起移动。**All Items** 可以在一个列表中查看整个资料库。文件夹中还可以创建文件夹。

搜索结果也可以选择并移动。输入搜索词后，点按 **更多 > Select**（在 **All Items** 中为右上角的 **Select**），即可一次选中分散在不同文件夹中的结果，并移到同一个文件夹。即使还没有文件夹，也可以在选择目标位置的页面中新建。更改搜索词后，选择会被清除。

### 2-3. 项目类型
列表中的图标和缩略图可以帮助你区分材料类型。

- **波形图标** - 从“文件”应用导入的音频
- **音符图标** - 从音乐库导入的曲目
- **天线图标** - 播客单集
- **YouTube 缩略图或播放图标** - YouTube 流媒体
- **胶片图标或视频缩略图** - 设备中的视频文件

点按项目会打开对应播放器。音频会打开音频播放器，YouTube 链接会打开 Stream 播放器，视频会打开视频播放器。

### 2-4. 删除
点按资料库行末尾的 **⋯**，或长按该行，然后选择 **Delete**。滑动行不会显示管理操作。**⋯** 和长按始终打开同一个菜单。

删除后，与该材料关联的波形缓存、书签、字幕、已保存的跟读录音和听写记录也会一起清理。如果该项目有已保存录音，删除前会显示确认窗口。删除文件夹时，可以选择只删除文件夹，或连同其中的材料一起删除。


### 2-5. 设置排序方式

在主屏幕或文件夹内，打开右上角的 **更多（⋯）> Sort By**，即可选择资料库的排序方式。当前选中的排序依据和方向旁会显示勾选标记。

| 排序依据 | 说明 | 选择时的默认方向 |
|---|---|---|
| **Recently Played** | 按最近播放或使用的时间排序，默认使用此依据 | **Newest First** — 最近的在前 |
| **Date Added** | 按添加到资料库的日期排序 | **Newest First** — 最新的在前 |
| **Name** | 按名称排序 | **A to Z** — 升序 |
| **Duration** | 按材料的总时长排序 | **Shortest First** — 最短的在前 |

排序依据下方会显示两个方向。日期可选 **Newest First / Oldest First**（最新优先／最早优先），名称可选 **A to Z / Z to A**（升序／降序），时长可选 **Shortest First / Longest First**（最短优先／最长优先）。再次点按已勾选的排序依据，也会反转方向。选择其他依据时，会使用上表中的默认方向。

设置会保存，并统一应用于**主屏幕、所有文件夹、搜索结果和 All Items**，无需为每个文件夹分别设置。上方的 **Recent** 区域始终按最近使用顺序显示，不受此设置影响。

文件夹始终显示在材料上方。选择 **Name** 时，文件夹跟随所选的名称排序方向；选择 **Date Added** 时，按文件夹的创建日期和所选方向排序。选择 **Recently Played** 或 **Duration** 时，文件夹按名称升序排列。从未打开过的 YouTube 链接等时长未知的材料，在 **Duration** 的两个方向中都会排在材料列表末尾。


## 3. 添加学习材料

点按主屏幕右上角的加号按钮，会打开添加菜单。

![添加学习材料菜单](images/iphone/11-add-menu.png)
*▲ 添加文件、音乐、YouTube 链接和播客的菜单*

### 3-1. 添加音频文件
点按 **Add Audio File** 会打开系统文件选择器。你可以导入 mp3、m4a、wav、aac 等音频文件，也可以一次选择多个文件。导入的文件会复制到应用的 Documents 区域，并添加到资料库。

### 3-2. 添加视频文件
点按 **Add Video File** 可以选择存放在设备或 iCloud Drive 中的视频。支持 MP4、M4V 和 MOV 文件，这是免费功能。

视频文件本身不会被复制到应用内。Phrabbit 只保存指向原文件的链接，因此原文件被移动或删除后就无法再播放。详情请见 [11. 视频文件练习](#11-视频文件练习)。

### 3-3. 从音乐库添加
点按 **Add from Music** 会打开设备中保存的音乐列表。

- 已添加到 Phrabbit 的曲目会显示对勾。
- 通过 Apple Music 订阅下载的曲目因 DRM 保护无法导入。
- 你直接购买或从 CD 转换的无 DRM 曲目可以使用。

点按曲目后，应用会准备成可播放格式，添加到资料库，并立即打开播放器。

### 3-4. 添加 YouTube 链接
点按 **Add YouTube Link** 会打开 YouTube 链接输入页面。

1. 在 YouTube 应用或浏览器中点按视频的 **Share**。
2. 点按 **Copy Link**。
3. 回到 Phrabbit，点按 **Paste**。
4. 确认缩略图无误后点按 **Add**。

视频通过 YouTube 嵌入播放器流式播放，不会下载到应用内。Phrabbit 保存链接、播放位置、书签、录音、听写记录，以及已加载或保存的字幕卡片、修改和翻译。

### 3-5. 添加播客
**Add from Podcast** 是高级版功能。高级版或免费试用期间，你可以按播客名称搜索、浏览适合练习语言的推荐内容，或从 Apple Podcasts 订阅列表和 RSS 地址导入单集。免费试用结束后，菜单会显示锁，点按后打开高级版页面。

详情请见 [14. 播客](#14-播客)。


## 4. 音频播放器

在主屏幕点按音频项目，会打开全屏播放器。

![音频播放器与字幕](images/iphone/04-subtitles.png)
*▲ 在同一屏幕显示波形和句子卡片的音频播放器*

### 4-1. 关闭与迷你播放器

| 方法 | 说明 |
|---|---|
| 左上角向下箭头 | 关闭播放器并返回主屏幕 |
| 从顶部向下滑动 | 用手把播放器下拉关闭 |

音频已加载时关闭播放器，主屏幕底部会显示迷你播放器。点按迷你播放器即可回到全屏播放器。

高级版用户如果开启 **Settings > Playback > Background playback**，音频可以在锁屏或后台继续播放。免费用户或关闭此设置的用户，在应用进入后台时音频会暂停。

### 4-2. 波形区域
波形按时间显示音频，竖直播放线表示当前位置；有字幕时，短刻度标记句子边界。轻点波形跳转，长按设置 A/B，拖动手柄微调。手柄可自由移动，不会吸附到句子刻度。

- 轻点波形旁的**缩放按钮**，可在每行 3、5、8、10 秒之间切换。双指缩放可在每行 2～15 秒之间细调。**7.5s** 表示每行 7.5 秒。
- 手动滚动可查看其他位置。**Current Position（◎）** 会让波形和字幕卡片一起回到当前播放位置，不会改变播放进度。
- 没有字幕时，波形会扩展到空余区域。较大屏幕还会显示播放行之后的下一行。

### 4-3. 标签与播放工具
顶部可切换 **Subtitles / Bookmarks / My Recordings / Dictation**。iPhone 显示图标，宽屏 iPad 还显示数量。窗口很窄时使用标签菜单。轻点音频标题可查看信息，标题旁是睡眠定时器。

固定工具栏从左到右为：

| 控件 | 功能 |
|---|---|
| 播放/暂停 | 开始或暂停播放 |
| **A-B** | 设置 A → 设置 B → 返回 A |
| 重复次数 | 无限、1、2、3、5、10 次 |
| 播放速度 | 0.5×、0.75×、1×、1.25×、1.5×、2× |
| 跟读间隔 | 在重复之间留出开口练习的静音时间 |
| 保存书签 | 立即保存当前 A/B 区间 |
| 练习 | 打开 Shadowing 或 Dictation |

工具上方的进度条可浏览整个文件，**−5 / +5** 每次跳转 5 秒。波形旁的 **×** 清除区间，**±** 打开微调。需要区间的工具在设置 A/B 前会变淡。

睡眠定时器可在 5、15、30、60 分钟后停止播放，并显示剩余时间。后台使用取决于 Premium 和 Background playback 设置。首次字幕从空的 **Subtitles** 标签创建；已有卡片时，通过右下角 **···** 打开字幕设置（第 7 章）。

在宽屏 iPad 横向窗口中，横跨两侧面板的顶部标题栏显示音频标题和睡眠定时器。左侧是波形和工具，右侧顶部是标签，下方是列表。纵向或窄窗口使用单列。

## 5. A/B 区间循环

A/B 区间循环是反复听一整句或短表达的核心功能。

![A/B 区间循环](images/iphone/02-abloop.png)
*▲ 用手指微调 A/B 区间并循环播放*

### 5-1. 用 A-B 按钮设置
1. 在想重复的起点点按 **A-B**。该位置成为 A。
2. 在终点再次点按 **A-B**。该位置成为 B，循环开始。
3. 区间设置后点按 **A-B**，会回到 A 点。

按钮会根据状态改变外观。

| 状态 | 含义 |
|---|---|
| A-B | 尚未设置区间 |
| A→B | 已设置 A，等待 B |
| 填充 A-B | A 和 B 都已设置，正在循环 |

只设置了 A 时，会显示 **Tap A-B again to set the end** 提示。如果误点了 A，可以点按提示右侧的关闭按钮取消。

### 5-2. 在波形上精确设置
长按波形上想要的位置即可设置 A/B 点。用手指拖动 A 和 B 手柄，可以更精确地调整位置。

### 5-3. 区间微调与清除
轻点波形旁的 **±**，以 **0.1 秒**为单位微调起点和终点。**×** 可清除 A/B，也可取消只设置了 A 的状态。Stream 和视频的相同按钮位于时间标尺两侧，以 **0.5 秒**为单位调整。

固定工具栏中的 **Practice** 打开跟读或听写。滚动句子卡片时，工具仍保持可用。

### 5-4. 跟读间隔
**Shadowing gap** 按钮固定在工具栏中，设置 A/B 后即可使用。开启后，每次循环之间会加入一小段静音时间，让你听完后自己说出来。即使不录音也可以使用，这是免费的练习功能。

静音时间进行时会显示 **Speak** 倒计时。

## 6. 书签与循环列表

书签用于保存你经常想练习的 A/B 区间。

### 6-1. 保存书签
1. 先设置 A/B 区间。
2. 轻点固定工具栏中的 **Save**。
3. 区间会立即以自动名称保存，并显示 **Bookmark saved** 提示。
4. 如果要立即命名，点按提示中的 **Rename**。也可以稍后从书签列表中修改名称。

自动名称根据文件标题和区间长度生成。相同区间不会重复保存。

### 6-2. 书签列表
打开当前文件的 **Bookmarks** 标签。轻点书签恢复并播放 A/B 区间。**My Recordings** 和 **Dictation** 各有独立标签，没有记录时也会显示。

![书签与我的录音](images/iphone/14-bookmarks-recordings.png)
*▲ 书签、录音和听写各有独立标签*

使用顶部标签切换书签、录音和听写记录。宽屏 iPad 的录音与尝试数量按区间分组计算，而不是单个录音。 音频文件有至少两个书签时，**Play All** 可按顺序播放，并让每个区间重复 1、2 或 3 次。仅适用于音频，不适用于视频或 YouTube。

点按书签行末尾的 **⋯**，或长按该行，会显示 **Rename**、**Info** 和 **Delete**。**Info** 会显示准确的 A/B 范围、区间长度和保存日期。已保存录音也可用同样方式选择 **Info** 或 **Delete**；信息页面会显示范围、长度、同一练习点的 take 数量和录音日期。滑动不会显示管理操作。

免费用户每个音频文件最多可以新建 1 个书签。高级版或免费试用期间可以无限创建。高级版或免费试用期间保存的书签，在回到免费状态后仍可从列表打开并练习，但无法超过免费上限继续新增书签。YouTube 流媒体的书签保存是高级版功能。

## 7. 语音转文字（STT）字幕

STT 会把音频转换成句子级字幕。高级版或免费试用期间可以使用。

![句子级自动字幕](images/iphone/01-sentences.png)
*▲ 将音频转换成句子级字幕卡片的画面*

### 7-1. 开始转换

语音识别需要 Premium 或免费试用。没有使用权限时，**Convert speech to subtitles** 会显示锁图标，轻点后打开 Premium 说明。仍可手动输入字幕。

![生成字幕或手动输入](images/iphone/41-audio-empty.png)

1. 打开 **Subtitles** 标签。没有字幕时，轻点 **Convert speech to subtitles**。
2. 轻点音频实际使用的语言，选择画面关闭后开始语音识别。

![语音识别语言](images/iphone/12-stt-language-picker.png)
*▲ 推荐语言与最近使用的识别语言*

推荐会参考之前的选择、播客 RSS 语言、标题和设备语言等。请确认与实际听到的语言一致。

已有字幕时，轻点右下角 **···** 打开 **Subtitles** 设置面板：

- **Add Segment** — 手动添加字幕。
- **Re-run with current language** — 用当前语言重新识别。
- **Change Language and Re-run** — 更改识别语言。
- **Subtitle Info** — 查看识别详情。
- **Delete Subtitles** — 删除语音识别生成且未改过文字的字幕，包括仅调整过时间的句子。手动添加、修改过文字的句子和播客创作者字幕会保留。

重新识别也会保留创作者字幕和手动修改的句子。删除前会要求确认。

重新语音识别和删除识别字幕需要 Premium；阅读已保存字幕和手动输入新句子免费。

**Subtitles** 设置面板会直接以完整高度打开。向下滚动可查看其余选项，也可以将面板向下拖到半高。

![音频字幕设置](images/iphone/38-audio-subtitle-settings.png)

### 7-2. 转换中

转换中会显示 **Converting...** 或 **Downloading language model...** 进度条。部分语言第一次使用时，可能需要下载设备端语音模型。

![STT 转换中](images/iphone/13-stt-converting.png)
*▲ 转换中会显示进度条和保持应用开启的提示*

重要事项：

- 转换中请保持应用打开。离开应用或锁屏可能会中断转换。
- 长音频可能需要几分钟。
- 如果取消，本次转换会停止，已有字幕会保留。
- 模型下载和部分恢复处理会受 Wi-Fi 设置影响。
- 如果识别结果为空，会显示 **Trying another recognition method…**，并换一种识别方式再试一次。如果仍无法生成字幕，会提示你确认音频能否正常播放、所选语言是否正确。如果文件无法完整读取，会提示你重新下载或导入。

### 7-3. 查看转换结果
转换完成后，字幕卡片会按时间顺序显示。

每张卡片可能显示：

- 开始时间
- 字幕来源标记
- 低可信度警告
- **Approx. position** 标记：文字已识别，但位置为近似值
- 字幕正文
- **⋯** 菜单中的 **Translate**、**Add to Wordbook**、**Edit**、**Delete** — 长按卡片会打开同一菜单

点按字幕卡片会把该卡片的区间设为 A/B，并立即循环播放。当前播放中的卡片会高亮，位于 A/B 区间内的卡片会使用不同背景色。带有单词时间信息的新语音识别字幕会随着播放进度，逐词点亮已经说到的位置。较早生成的字幕或导入的字幕可能没有单词时间信息，因此不一定显示此效果。

结束手动滚动后，当播放到达屏幕内可见的字幕卡片时，自动跟随会恢复。**Current Position（◎）**可立即将音频波形和卡片带回当前播放位置。选择要隐藏的句子时，跟随会暂停。

### 7-4. 未识别的区间
无声或难以识别的区间可能会显示为 **Could not recognize** 卡片。这类卡片仅作提示。如需为该区间手动添加字幕，请把播放位置移到该区间，再点按 **Add Segment**（参见 8-1）。

### 7-5. 查看字幕信息
通过右下角 **··· > Subtitle Info** 查看转换时间、识别引擎、质量说明及有无单词时间信息。自动字幕可能有误，请核对并修改重要表达。

### 7-6. 隐藏字幕
轻点字幕卡片右下角悬浮的眼睛按钮，隐藏或显示文字。隐藏卡片仍显示开始时间和 **Subtitle hidden**，轻点仍可循环该句。通过 **··· > Hide subtitles** 选择 **Entire file / Entire video**、**Selected sentences** 或 **A/B range**。选择句子时轻点卡片勾选，再按 **Done**。A/B 隐藏范围会随区间改变。

![Hide subtitles](images/iphone/35-subtitle-hide-menu.png)

音频、本地视频和 YouTube 字幕卡片均可使用。播放器内切换标签会保留状态，关闭播放器后重置。可先听再用眼睛按钮查看文字。全屏字幕面板共享普通画面的隐藏状态；请在普通画面选择范围与句子。

![A/B range hidden](images/iphone/36-subtitle-hide-ab.png)

## 8. 编辑、翻译与手动添加字幕

### 8-1. 手动添加字幕
在音频 Subtitles 标签打开 **··· > Add Segment**。没有字幕时选择 **Type subtitles yourself**。编辑页面默认打开从当前播放位置开始的 5 秒区间。在顶部的 **Adjust timing** 中，可以看着波形拖动开始和结束手柄，或用 **Start**、**End** 旁的按钮以 0.1 秒为单位调整，并用播放按钮只试听该区间（参见 8-2）。然后手动输入文本。

如需重新识别语音，请在 **Recognition language** 中确认语言，然后点按 **Recognize again**。结果会先以预览显示，不会自动覆盖编辑器中的内容。确认可用后，点按 **Put in editor** 放入编辑框，按需修改，再点按顶部的 **Add** 保存。

### 8-2. 编辑字幕
点按字幕卡片的 **⋯**，或长按卡片后选择 **Edit**，即可打开编辑页面。除了文本，也可以修改该句的开始和结束时间。

- **Adjust timing** - 拖动波形上的开始和结束手柄，或用 **Start**、**End** 旁的 −/+ 按钮以 0.1 秒为单位移动。波形下方的按钮可查看前后的音频、放大或缩小，中间的按钮可让视图重新对准该句区间。点按播放按钮只播放调整后的区间。
- **Adjacent sentence timing changes** - 如果把边界延伸到前一句或后一句，相邻句子会按重叠的部分缩短，这里会预先显示变化。之后再把边界缩回时，借用的部分会还给相邻句子。原本就与本句重叠的相邻句子不会改变。
- **Restore original range** - 修改时间后，**Original range** 会显示原来的区间，用这个按钮可以随时恢复。如果因为前后句子当前的边界而无法恢复，会提示你手动调整。
- **Restore original text** - 修改 STT 生成字幕的文本后，原文会一起显示，用这个按钮可以恢复原文。

![调整句子时间](images/iphone/37-segment-timing.png)
*▲ 使用波形手柄和 0.1 秒按钮调整句子时间，也可恢复原始区间。*

在编辑页面中，也可以用 **Recognize again** 只重新识别当前设置的区间，再用 **Put in editor** 将预览结果放入编辑框。时间和文本都只有在点按顶部的 **Save** 后才会保存。

![只重新识别一个区间](images/iphone/26-segment-recognition.png)
*▲ 重新识别的结果只作为预览显示，编辑框中的内容保持不变*

### 8-3. 翻译全部字幕
在 iOS 26.4 或更高版本、支持 Apple Intelligence 的设备上，可通过右下角翻译按钮或 **··· > Translation** 开始 **AI Translation**。需要 Premium 或免费试用。字幕语言会自动识别并显示在 **Subtitle language** 中。在 **Translation language** 中选择支持的目标语言，确认翻译对象后按 **Start translation**。音频和字幕不会上传，保存的结果可在下次打开时复用。音频、本地视频和已加载的 YouTube 字幕使用相同流程。

翻译期间会显示进度。关闭应用或播放器会安全暂停任务，之后可用 **Continue translation** 继续。较长的材料可能耗时较久并让设备变热；Phrabbit 会在需要时自动降低速度。任务开始后，还会提供在本次翻译期间保持屏幕常亮的选项。

气泡按钮切换 **Original only / Original + translation**。在 **··· > Translation** 中可明确选择 **Translation only**，更改语言、继续或重试，以及删除保存的 AI 翻译。双语视频字幕的文件翻译和 AI 翻译是独立来源（11-4）。

![英语字幕与日语 AI 翻译](images/iphone/25-subtitle-translation.png)

※ 示例：将英语字幕翻译成日语。在 **AI Translation** 中，可以从支持的语言中选择所需的目标语言。

如果无法开始翻译，会显示 **AI translation unavailable** 提示，说明当前的一项原因，而不会打开设置面板。例如 Apple Intelligence 未开启、模型尚未准备好、无法识别字幕语言或语言不受支持。解决提示中的原因后再试。不支持的设备或 iOS 版本不会显示 AI 翻译入口。机器翻译可能误译专有名词、文化表达和专业术语，重要内容请与原文对照。

### 8-4. 翻译单句
在字幕卡片的 **⋯** 中选择 **Translate**，会打开 iOS 系统翻译页面。翻译仅作为学习辅助，可能会因上下文而不准确。

![字幕翻译](images/iphone/09-translate.png)
*▲ 直接翻译并确认字幕句子的画面*

视频和 YouTube 卡片中，此操作名为 **Translate this sentence**，在系统面板翻译单句；**AI Translation** 则保存材料的翻译。

### 8-5. 添加到单词本
在字幕卡片的 **⋯** 中选择 **Add to Wordbook**，可以从该句中挑选单词或表达并保存到单词本。单词本本身是高级版功能，因此免费试用结束后会打开高级版页面。

单词本用于集中复习从字幕卡片中保存的单词和表达。高级版或免费试用期间可以使用。

*▲ 将表达连同上下文一起保存的单词本*

可以保存的内容：

- 含义
- 学习上下文
- 上下文翻译
- 备注
- Apple Intelligence 说明

你可以选择从句子中自动提取的单词标签，也可以在 **Custom Input** 中直接输入。像英语这样有空格的语言会按单词显示；日语和中文会由应用重新分词，尽量显示更自然的单位。

### 9-3. Apple Intelligence 说明

*▲ 为所选单词生成上下文含义和例句的 AI Explanation*

## 10. YouTube 流媒体练习

添加 YouTube 链接后，会打开 Stream 播放器。YouTube 视频不会保存在应用内，而是通过 YouTube 嵌入播放器播放。

![YouTube 流媒体练习](images/iphone/03-youtube.png)
*▲ YouTube 视频、固定工具和字幕卡片同时显示。*

### 10-1. 基本结构
YouTube 画面下方固定显示时间标尺和七个工具：播放/暂停、A-B、重复次数、速度、跟读间隔、保存书签和练习。顶部可切换 **Subtitles / Bookmarks / My Recordings / Dictation**。只有列表滚动，方便边读字幕边调整区间。

轻点字幕卡片即可循环该句。手动滚动会暂停跟随，用 **Current Subtitle（◎）** 返回当前句。右下角眼睛、翻译和 **···** 按钮用于隐藏字幕与打开设置。

结束滚动后，播放到达屏幕内可见的卡片时会恢复跟随，也可以用 ◎ 立即返回当前句子。

在宽屏 iPad 横向窗口中，横跨屏幕的顶部栏显示缩略图、标题和全屏按钮。视频与工具位于左侧，标签位于右侧列表的顶部。

### 10-2. YouTube 字幕卡片
视频提供字幕时，Premium 或免费试用期间可将 YouTube 字幕加载为 Phrabbit 卡片。请先播放一次视频：播放开始后才会收到可用轨道列表。通过 **··· > Subtitle Track** 切换，使用 **Re-download from YouTube** 重新加载。替换修改过的字幕前会要求确认。

卡片支持句子循环、隐藏、单句系统翻译、支持设备上的 AI 翻译、**Add to Wordbook** 和字幕编辑，也可作为跟读参考与听写答案。YouTube 自动生成字幕可能存在错误。

试用结束后，已保存的卡片仍可阅读和重新加载。获取新视频的字幕或选择另一轨道需要 Premium。没有权限时，字幕标签显示锁定说明和升级按钮。YouTube 自带 **CC** 仍可使用。卡片加载失败时，可选择 **Try Again** 或使用视频的 CC。没有字幕的视频不会提供卡片。

Phrabbit 不会对 YouTube 音频生成 STT 字幕，也不能显示其原始波形；可以使用 YouTube 提供的字幕。

![YouTube 字幕轨道与设置](images/iphone/39-youtube-subtitle-settings.png)

### 10-3. Full-screen Practice
通过顶部展开按钮打开 **Full-screen Practice**，可放大视频并继续使用 A/B 工具。卡片按钮在视频旁打开句子面板。轻点卡片可循环句子，面板的眼睛和翻译按钮与普通画面共享显示状态。开始翻译、选择隐藏范围和编辑卡片请在普通画面操作。

使用 **Hide / Show** 收起或展开 Phrabbit 全屏工具。轻点 YouTube 画面由 YouTube 处理，向内的对角箭头按钮 **Exit full screen** 始终保留，轻点后返回普通播放器并继续播放。iPhone 会旋转应用内的显示区域，无需关闭设备旋转锁定。

### 10-4. 时间标尺
Stream 使用时间标尺，而不是音频波形。

- **拖动** - 移动视频位置
- **长按** - 设置 A/B 点
- **捏合** - 放大/缩小标尺
- **调整 A/B 手柄** - 精细调整区间

YouTube 嵌入播放器不会向应用提供实际音频样本，因此 Phrabbit 使用时间标尺，而不是伪造波形。

### 10-5. YouTube 后台行为
YouTube 流媒体不会在锁屏或后台继续播放。当应用进入后台时，Phrabbit 会停止视频并记住位置，回到应用后再恢复该位置。这是 YouTube 嵌入播放器和 iOS WebKit 的限制。


## 11. 视频文件练习

存放在设备或 iCloud Drive 中的视频文件同样可以作为学习材料。视频也能使用与音频相同的 A/B 区间循环、跟读、听写和书签功能，字幕则通过导入单独的字幕文件来使用。

![视频播放器](images/iphone/20-video-player.png)
*▲ 同时显示字幕、带 A/B 的时间标尺和已保存书签的视频播放器*

### 11-1. 添加视频文件
在主屏幕的加号菜单中点按 **Add Video File**，然后选择视频。这是免费功能。

支持的格式为 **MP4、M4V 和 MOV**。MKV、AVI、WebM 等格式无法在文件选择界面中选取。

即使是支持的格式，文件里的视频或音频也可能采用本设备无法解码的编码方式。这种情况下，应用会说明检测到的编码方式。把文件转换为 H.264 或 HEVC 视频 + AAC 音频后即可播放。

有一种情况容易混淆：文件本身已经是 HEVC，但封装为 `hvc1` 以外的 `hev1` 格式。iOS 无法播放 `hev1` 封装。此时只需把它重新封装（remux）为 `hvc1` 即可，不需要重新编码视频。

### 11-2. 视频是引用原文件，而不是复制
音频文件会被复制到应用内，但视频文件仍留在原来的位置。Phrabbit 只记住指向原文件的链接。

实际使用中的差别如下：

- 添加视频几乎不占用应用容量，无论文件多大。
- 如果移动、重命名或删除原文件，就无法再播放。iCloud Drive 中的文件从该账户删除，或从设备上被移除时也一样。
- 找不到文件时，资料库列表会显示 **File missing** 警告，打开该项目会看到带有 **Re-link File** 和 **Remove** 的界面。用 **Re-link File** 重新选择新位置的文件后，书签、字幕和播放位置都会原样保留，可以继续练习。
- 如果重新链接的文件长度与原视频明显不同，会显示 **Different video length** 提示，因为循环区间和字幕位置可能会对不上。

首次播放存放在 iCloud Drive 且尚未下载到设备的视频时，会显示 **Preparing video…**，系统会先下载文件，长视频可能需要一些时间。下载完成后，无论文件多大都会立即打开。

### 11-3. 视频播放器
普通视频画面与 Stream 使用相同的四个标签和七个工具。切换 **Subtitles / Bookmarks / My Recordings / Dictation**，时间标尺与 A/B 工具固定在滚动列表上方。

- 轻点视频播放/暂停。进度条叠加在画面底部，播放时自动隐藏；轻点画面或操作播放工具可再次显示。
- 标尺旁的 **±** 用于微调，**×** 清除区间。**Practice** 位于工具栏。
- 字幕以工具下方的句子卡片显示。阅读卡片时可同时调整 A/B。
- 没有字幕时，在 Subtitles 标签选择 **Import subtitle file…** 或区间语音识别。顶部展开按钮进入全屏。
- 在宽屏 iPad 横向窗口中，横跨屏幕的顶部栏显示缩略图、标题和全屏按钮。左侧是视频和工具，右侧顶部是标签，下方是列表。纵向或窄窗口使用单列。

视频没有波形。免费用户每个视频可新建一个书签，Premium 或试用期间不限数量。已保存的书签仍可打开。

### 11-4. 使用字幕文件
可导入独立的 **SRT、VTT、SMI（SAMI）** 字幕文件，不读取视频内嵌字幕轨道。没有字幕时使用 Subtitles 标签的 **Import subtitle file…**；已有字幕时使用右下角 **··· > Replace subtitle file…**。

保存前可在附件预览中检查字幕语言和示例句子。支持的双语文件可选择或交换**原文字幕**与**文件翻译**轨道，也可不导入翻译或保留未拆分的文本。可拆分 SMI 语言轨道，以及 SRT/VTT 中位于不同行的英语和韩语；同一行混合的文字不会自动拆分。**Change** 可修正用于生词本、发音和 AI 翻译的语言。确认附加后才生效，取消会保留原有字幕。

显示文件翻译不需要 Apple Intelligence 或 Premium。在 **··· > Translation** 中选择仅原文、原文+翻译或仅翻译。可用时，通过 **Translation source** 切换 **File subtitles / AI Translation**。删除 AI 翻译不会删除文件翻译。AI 翻译仍需满足支持设备和 Premium 条件。

同一设置面板还提供区间字幕生成、**Subtitle Sync…**（0.5 秒步进）、可恢复时的 **Restore Original Subtitles…**、隐藏范围和 **Delete Subtitles**。句子编辑与添加生词本在卡片 **⋯** 中。普通画面使用卡片，全屏关闭卡片面板后也可显示画面字幕。

建议使用 UTF-8，也支持带 BOM 的 UTF-16 和常见旧式 SMI 编码。读取失败时请另存为 UTF-8 后重试。

### 11-5. 逐句练习
每张卡片会合并属于同一句的字幕行。轻点后该句成为 A/B 并重复，不会自动跳到下一张。字幕同步调整也会应用到卡片。

![句子卡片](images/iphone/28-subtitle-practice.png)
*▲ 句子卡片与固定练习工具同时显示*

当前句会高亮。滚动查看其他句子后，可用 **Current Subtitle（◎）** 返回。右下角眼睛按钮隐藏文字，同时保留时间与循环功能；**···** 可选择整个视频、选定句子或 A/B 范围。翻译按钮切换仅原文与原文+翻译，仅翻译需在设置中选择。

结束滚动后，播放到达屏幕内可见的卡片时会恢复跟随，也可以用 ◎ 立即返回当前句子。

### 11-6. 转写这个场景
视频不支持整个文件的语音转文字，但可以只转写你正在练习的区间。此功能在高级版或免费试用期间可用。

1. 在需要的部分设置 A/B 区间。
2. 在 Subtitles 标签的 **···** 中选择区间字幕生成。没有字幕时，使用空标签中的区间识别按钮。
3. 选择该场景所说的语言。

注意事项：

- 区间超过 **10 分钟**时无法转写，请先缩短 A/B 区间。
- 区间超过 3 分钟，或设备已经发热时，会先显示 **Transcribe This Scene?** 提示，点按 **Continue** 即可继续。如果设备温度过高，应用只会提示你等它冷却，不会执行。
- 如果该区间已有来自字幕文件的字幕，会先显示 **Replace Subtitles in Range?** 确认框。只有区间内的字幕会被替换，原有字幕会被保留，可以用 **Restore Original Subtitles…** 恢复。

### 11-7. 全屏与后台
![全屏练习](images/iphone/21-video-fullscreen.png)
*▲ 全屏时也能同时保留 A/B 控制和字幕*

点按全屏按钮可以放大视频。应用本身保持竖屏，同时把画面横向铺满，因此不需要解除设备的屏幕旋转锁定。全屏时点按视频可以显示或隐藏控制项，也可以用书签列表在已保存的区间之间跳转。

轻点向内的对角箭头（**Exit full screen**）可返回普通播放器。隐藏其他全屏工具后，此按钮仍然可见；退出全屏不会停止播放。

全屏时也可以用卡片按钮，把同一份句子列表显示在视频旁边。列表不会遮住画面：视频、时间标尺和进度条会向一侧让出位置，关闭面板后恢复原来的宽度。

![全屏中的句子卡片](images/iphone/29-subtitle-practice-fullscreen.png)
*▲ 全屏时卡片位于视频旁边，而不会遮住画面*

视频不会在后台或锁屏时播放。应用进入后台或屏幕锁定时，播放会停止。后台播放仅适用于音频文件。

### 11-8. 重命名、信息与删除
视频标题最初显示为文件名。点按资料库行末尾的 **⋯**，或长按该行，然后选择 **Rename** 即可修改。**Info** 会显示完整标题、项目类型、时长、添加日期和文件夹位置。

在同一菜单中选择 **Delete**，会清理 Phrabbit 中的项目信息以及字幕、书签、已保存的跟读录音和听写记录。**原始视频文件不会被删除。** 如果存在已保存的录音，删除前会先显示确认框。


## 12. 跟读录音与比较

跟读功能让你听 A/B 区间、自己说出来，并把自己的录音与原音比较。

![跟读](images/iphone/10-shadowing.png)
*▲ 听 A/B 区间、录音并与原音比较的跟读画面*

### 12-1. 跟读间隔
这是无需录音也能使用的练习方式。

1. 设置 A/B 区间。
2. 开启跟读间隔按钮。
3. 区间播放后出现静音时间时，自己跟着说。
4. 倒计时结束后，原音会再次播放。

此功能可用于音频、视频和 YouTube 流媒体。

### 12-2. 录音与比较
录音/比较是高级版功能。

1. 设置 A/B 区间。
2. 轻点固定工具栏中的 **Practice**。
3. 在顶部选择 **Shadowing**，再用 **Listen** 听原音区间。
4. 点按 **Record** 录下自己的声音。
5. 用 **My take** 只听自己的录音。
6. 用 **Compare** 连续比较原音和自己的录音。

首次使用时会请求麦克风权限。录音会保存在设备内。

音频文件中可以同时看到原音波形和自己的录音波形。视频和 YouTube 流媒体无法获取原音波形，因此只显示自己的录音波形。

### 12-3. 配合字幕练习
选定 A/B 区间与字幕卡片重叠时，文字会传入练习画面。已加载的 YouTube 字幕和本地视频字幕也可使用。跟读时可边听边看参考句，听写则在核对前隐藏答案。没有字幕也可听音和录音。

### 12-4. 保存并重新打开自己的录音
使用保存按钮保留喜欢的录音。打开原始材料的 **My Recordings** 标签即可查看，同一 A/B 区间的录音会分为一组。

点按保存的录音，会回到创建该录音时的 A/B 区间，并重新打开跟读画面。同一区间的多个 take 会作为一个练习点分组显示。

管理已保存录音或书签时，可点按行或卡片末尾的 **⋯**，或长按它。两种方式会打开同一个菜单；滑动不会删除已保存练习。选择 **Info** 可以查看书签的范围、长度和保存日期，或录音的范围、长度、take 数量和录音日期。


## 13. 听写

听写是一项高级版练习功能：逐题聆听 A/B 区间，写下所听内容，再与原文比较。音频、视频和 YouTube 都可使用，免费试用期间也可以体验。

### 13-1. 开始听写
1. 设置要练习的 A/B 区间。
2. 轻点固定工具栏中的 **Practice**。
3. 在顶部选择 **Dictation**。下次再次打开时，Phrabbit 会记住你最后使用的练习模式。

![听写模式](images/iphone/30-dictation-mode.png)
*▲ 顶部带有 Shadowing / Dictation 切换的练习面板，已选择 Dictation*

已加载的字幕可作为答案参考。音频可按句练习；视频和 YouTube 使用选定 A/B 区间的字幕参考。没有字幕时，可自己输入答案或查看视频。听写从普通播放器开始，不在全屏练习中开启。

### 13-2. 听并写下
用 **Listen** 听一遍当前句子，然后用键盘输入所听内容。可以播放或暂停、前后移动 2 秒，并调整播放速度。点按速度按钮会一次显示从 0.5× 到 2× 的 6 个选项。写完后点按 **Check answer**。

![听并写下](images/iphone/31-dictation-typing.png)
*▲ 键盘上方显示播放控制、速度和 Check answer 的输入画面*

在宽屏 iPad 窗口中可以切换 **Keyboard** 和 **Handwriting**。手写页面提供笔颜色、荧光笔、橡皮擦、撤销、全部清除和手指书写设置。笔迹会原样保存，但 Phrabbit 不会识别或自动批改手写内容，请自行对照原文。输入方式的选择会保留到下次练习。在 Split View 或 Stage Manager 中窗口较窄时，只显示键盘输入。

![iPad 手写](images/ipad/34-dictation-handwriting.png)
*▲ 宽 iPad 窗口中的手写页面：纸面上方有笔的颜色、荧光笔、橡皮擦、撤销和全部清除，左下角是键盘 / Handwriting 切换*

### 13-3. 核对与评分
有字幕或自己保存的答案时，Phrabbit 会自动比较你的输入与原文并标出差异。对于新识别的音频，如果 A/B 区间截断了一个句子，单词时间信息会让应用只比较实际听到的部分。被截断的句子如果没有精确的单词时间，可能不会自动比较。此时可用 **Whole sentence** 练习完整句子并恢复自动比较，再用 **My range** 回到原区间。

![核对答案](images/iphone/32-dictation-check.png)
*▲ 标出与原文差异的比较结果，以及 Try again 和 Next*

没有字幕时，可查看视频，或输入实际发言并保存为此 A/B 区间的答案。**修改此区间的答案**只修改个人答案，不改变字幕和之前的输入。可恢复使用当前字幕；没有字幕时可删除输入的答案。独立的**修改字幕**会修改字幕本身。**Restore original text** 将原文填回编辑框，保存后才生效。语音识别和 YouTube 自动字幕可能有误，请先核对比较依据。

在 iPhone 或较窄的 iPad 窗口中，点按 **Check in the video** 会降低听写面板，让你直接操作视频和 YouTube 控件。在宽屏 iPad 上则会打开专用练习工作区：书写时视频隐藏，核对答案时视频会重新出现在比较内容上方。

核对后，选择 **Try again** 会把同一道题放到本次练习末尾再问一次，选择 **Next** 则继续。最后一道题会显示 **Finish**。

### 13-4. 查看记录并再次练习
至少填写或核对一题后，关闭会话时会自动保存。在原始材料的 **Dictation** 标签查看按 A/B 区间分组的尝试。

打开记录后，可以查看输入内容、原文、自动比较结果和已保存的手写内容。同一区间练习多次时，可用 **Attempt** 标签切换以前的尝试。可用 **Practice again** 重新练习同一区间，或删除不需要的尝试。高级版结束后仍可查看已保存记录，但开始新的听写需要高级版或免费试用。

![听写记录](images/iphone/33-dictation-attempts.png)
*▲ 已保存的记录：Attempt 切换、所写内容、原文和 Practice again*

在听写画面中聆听和书写的时间会计入学习记录。切换到其他应用时会暂停计时，长时间没有操作也会自动暂停。


## 14. 播客

播客下载是高级版功能。你可以按节目名称搜索、浏览适合练习语言的推荐内容，或从 Apple Podcasts 订阅列表和 RSS 地址导入单集，并在音频播放器中练习。

### 14-1. 按练习语言浏览
在主屏幕加号菜单中点按 **Add from Podcast**。首次打开时，先选择你想练习的语言。韩语、英语、日语、中文、西班牙语和法语有 Phrabbit 精选列表，也可以选择其他练习语言。

选择语言后，**Browse in …** 下方会显示主题标签和节目列表。默认会选择学习者节目和最新新闻等主题。开启或关闭标签，可添加或隐藏初级、慢速、历史、旅行、音乐等列表。每种语言只显示有实用搜索结果的主题。可随时用 **Change language** 更换语言。

![选择练习语言](images/iphone/23-podcast-language.png)
*▲ 首次打开时先选择要练习的语言*

![按语言浏览播客](images/iphone/24-podcast-browse.png)
*▲ 用主题标签筛选列表，每一行都可以横向滑动*

**Chosen by Phrabbit** 表示 Phrabbit 精选列表；**Apple Podcasts search results** 表示 Apple 的搜索结果。“英语讲解”等标记表示该节目使用练习语言以外的另一种语言进行说明。

### 14-2. 按名称或 RSS URL 搜索
在顶部的 **Search podcasts or RSS URL** 中输入节目名称并搜索。点按节目卡片后，无论从哪个入口进入，都会打开同一个单集列表。也可以把 RSS URL 直接粘贴到此输入框中打开订阅源。

### 14-3. Apple Podcasts 订阅列表
首次使用时可能会请求媒体资料库权限。点按 **Load from Apple Podcasts** 并允许访问后，订阅的节目会显示在 **My podcasts** 中。此权限只用于显示你感兴趣的节目；单集音频由 Phrabbit 直接从各节目的 RSS 源下载。

点按频道会打开单集列表。

### 14-4. 单集标记

| 标记 | 含义 |
|---|---|
| **Creator captions** | 提供带时间信息的官方字幕 |
| **Creator transcript** | 提供纯文本官方资料 |
| 无标记 | 无官方字幕 |

![带 Creator captions 标记的播客单集](images/iphone/17-podcast-script.png)
*▲ 带 Creator captions 标记的单集可以同时导入官方字幕*

带 **Creator captions** 标记的单集，不需要应用重新运行 STT，而是可以导入播客提供的官方字幕。通常比自动识别更准确，也不需要等待太久，因此选择学习材料时建议优先使用这些单集。

### 14-5. 直接输入 RSS 地址
除了把 RSS URL 粘贴到搜索框，还可以展开 **Add via RSS URL (advanced)** 手动输入。适合 Apple Podcasts 搜索不到的播客，或你已经知道 RSS 地址的情况。

### 14-6. 下载与蜂窝网络
默认设置是 **Download over Wi-Fi only**。如果允许蜂窝网络下载，在下载大型单集前可能会显示确认窗口。

![播客下载状态](images/iphone/18-podcast-downloads.png)
*▲ 可在单集列表中确认未下载和已下载状态*

点按单集会开始下载。下载期间，点按进度环中的停止方块即可取消。如果时钟图标表示正在等待 Wi-Fi，再次点按该单集可将其移出队列。点按带对勾的单集会打开播放器。

部分播客文件首次播放时，应用可能需要一点时间准备成可播放格式。带有官方字幕或 STT 字幕的单集，可在支持的设备上使用 [8-3. 翻译全部字幕](#8-3-翻译全部字幕)。

## 16. 免费版 vs 高级版

### 免费可用功能

- 导入本地音频文件
- 导入音乐库中无 DRM 的曲目
- 添加 YouTube 链接并进行 A/B 循环练习
- 添加视频文件并进行 A/B 循环练习
- 为视频导入字幕文件（SRT、VTT、SMI）
- 查看波形、时间标尺和 A/B 区间循环
- 调整循环次数和播放速度
- 跟读间隔
- 睡眠定时器
- 每个音频文件新建 1 个音频书签
- 每个视频新建 1 个视频书签
- 打开高级版或免费试用期间保存的既有音频书签
- 隐藏已有字幕的音频、本地视频和 YouTube 卡片；编辑音频句子时间

## 17. 常见问题

**Q. 可以导入通过 Apple Music 订阅听的歌曲吗？**

A. 通过 Apple Music 订阅下载的歌曲带有 DRM 保护，无法在其他应用中使用。只有从 iTunes Store 直接购买或从 CD 转换的无 DRM 曲目可以导入。

**Q. 语音识别结果不准确。**

A. 请先确认音频的实际语言与所选 STT 语言一致。背景音乐、噪音、多人同时说话的区间都可能难以识别。重要部分建议用字幕编辑或 Add Segment 手动修正。

**Q. STT 转换中离开应用会继续吗？**

A. 不会。目前 STT 转换需要保持应用打开。锁屏或切换到其他应用可能会中断转换。音频后台播放和 STT 转换是不同功能。

**Q. 听写中为什么没有自动比较？**

A. 自动比较需要可用字幕或已保存答案。已加载的 YouTube 卡片也可提供参考。没有精确时间信息且截断句子的区间可能需要手动核对。可用时选择 **Whole sentence**，或保存该区间答案。手写按笔迹保存，始终需要手动比较。

**Q. 音频会在锁屏时继续播放吗？**

A. 需要 Premium 或免费试用并开启 **Background playback**。在锁屏、控制中心或支持的耳机上，可播放/暂停以及上一项/下一项。上一项/下一项在句子间移动；Play All 时在书签间移动。没有字幕时改为每次跳转 5 秒。关闭后台播放或试用结束后，进入后台会暂停音频。

**Q. 添加视频会占用应用容量吗？**

A. 几乎不会。视频文件不会被复制到应用内，Phrabbit 只保存指向原文件的链接。代价是：一旦原文件被移动、重命名或删除，或者 iCloud Drive 中的文件不再下载到本设备，就无法播放。这时用 **Re-link File** 重新链接文件即可。

**Q. 视频显示“File missing”。**

A. 说明原文件已被移动、重命名或删除，或者尚未下载到本设备。打开该视频并点按 **Re-link File**，然后选择新位置的文件。书签、字幕和播放位置都会保留。如果文件已彻底删除，可以用 **Remove** 清理该项目。

**Q. 是 MP4 文件，却无法播放。**

A. 格式（容器）是支持的，但其中的视频或音频可能采用本设备无法解码的编码方式。转换为 H.264 或 HEVC 视频 + AAC 音频即可播放。如果提示中出现 `hev1`，说明编解码器本身是 HEVC，只是封装成了 iOS 无法播放的形式，把它重新封装（remux）为 `hvc1` 就可以了，不需要重新编码视频。

**Q. 视频也会在后台播放吗？**

A. 不会。应用进入后台或屏幕锁定时，视频播放会停止。后台播放仅适用于音频文件。

**Q. YouTube 也会在后台继续播放吗？**

A. 不会。YouTube 流媒体不支持后台播放。应用进入后台时会停止视频并记住位置，回到应用后恢复该位置。

**Q. YouTube 视频无法在应用内播放。**

A. 部分视频的所有者不允许在 YouTube 外部播放，因此嵌入播放器无法播放。这种情况下无法在 Phrabbit 中使用。

**Q. 数据会发送到互联网吗？**

A. 单词本、书签、字幕和录音保存在设备上。STT 会尽可能使用设备端模型。但根据语言、iOS 版本和模型安装状态，可能需要 Apple 的语音识别服务或模型下载。**Download over Wi-Fi only** 设置也适用于模型下载和部分基于网络的恢复处理。YouTube 视频通过 YouTube 嵌入播放器播放。

**Q. Apple Intelligence 说明总是准确吗？**

A. 不一定。这是测试版功能，可能出错。保存到单词本前，请自行确认含义、例句和说明，并根据需要修改。

**Q. 看不到 AI Explanation。**

A. 此功能需要 iOS 26 或更高版本、支持 Apple Intelligence 的设备、已启用且准备好的 Apple Intelligence，以及受支持的学习语言和设备语言。如果无法判断学习语言，或该语言不受模型支持，区块可能不会显示。相同语言下，iOS 翻译功能也可能无法生成单独翻译，必要时请手动输入。

**Q. 保存的录音在哪里？**

A. 打开原始材料，选择 **My Recordings** 标签；听写记录在 **Dictation**。删除原始项目会删除关联练习记录，删除视频项目不会删除原始视频文件。

**Q. 更换设备后学习数据也会转移吗？**

A. 目前应用的学习数据默认保存在设备内。使用同一 Apple ID 点按 **Restore Purchase** 可以恢复高级版购买，但单词本、书签、字幕、录音等学习数据不会自动转移到其他设备。
